# Observatorio de Responsabilidad Social y Sostenibilidad

Login y landing principal con diseño inspirado en la guía `DESIGN.md`: gradiente cielo, tipografía Geist, grano sutil y estética editorial.

## Stack

- Astro 7
- Tailwind CSS 4
- Geist (fuentes)

## Estructura

- `src/pages/index.astro` — página de login.
- `src/styles/global.css` — tokens de diseño y estilos base.
- `DESIGN.md` — guía de diseño detallada.

## Comandos

Todos los comandos se ejecutan desde la raíz del proyecto:

| Comando | Acción |
| :-- | :-- |
| `pnpm install` | Instala dependencias |
| `pnpm dev` | Inicia el servidor en `localhost:4321` |
| `pnpm build` | Genera `dist/` para producción |
| `pnpm preview` | Previsualiza el build |
| `pnpm astro ...` | Ejecuta comandos del CLI de Astro |
